# 代码逻辑

目标：寻找“第一个真”
##  情况1

 ```
      A              B
 |____________|______________|
 l                           r
 ```
 `if ( check(mid) )`判断mid是否符合在A：
若true: (mid存在于A区间) 
区间更新为如下：
```
      A              B
 |_______,_____|______________|
 l      mid                   r
```
目标答案在`[mid, r]`
更新: `l = mid;`

---
	若false:
	区间更新为如下:
```
      A              B
 |____________|____,________|
 l                mid       r
```
目标答案在`[l, mid-1]`
更新: `r  = mid -1;`

接着递归。。。

上述为`[l, mid-1]`+`[mid, r]`型，
此时`mid = (l + r + 1) / 2;`
使用如下模板：
```c
int bsearch(int l, int r){
	while(l<r){
		int mid = (l + r) / 2;
		if (check(mid)) r = mid;
		else l = mid + 1;
	}
}
```

##  情况2

此时通过`if ( check(mid) )`判断mid是否符合在B：
则为`[l, mid]`+`[mid+1, r]`
此时`mid = (l + r) / 2;`
使用如下模板：
```c
int bsearch(int l, int r){
	while(l<r){
		int mid = (l + r + 1)/ 2;
		if (check(mid)) l = mid;
		else r = mid - 1;
	}
}
```
